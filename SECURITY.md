# Security Policy

## Supported versions

Security fixes are released for the latest version only. Please update to it before reporting.

| Version | Supported |
|---|---|
| 1.3.x | Yes |
| < 1.3 | No |

## Reporting a vulnerability

Please report vulnerabilities **privately**. Do not open a public issue or pull request, and do not disclose details publicly until a fix is released.

Use GitHub's private vulnerability reporting: open the [Security tab](https://github.com/gmaccario/lead-magnet-locker/security) of this repository and choose **Report a vulnerability**.

Please include:

- the plugin version, and your WordPress and PHP versions;
- the web server (Apache, Nginx, …), if relevant;
- steps to reproduce, or a proof of concept;
- the impact you see (for example: who can do what, without which permission).

## What to expect

- An acknowledgement within 7 days.
- An assessment and, if the report is confirmed, a fix released on wordpress.org as soon as practical.
- Credit in the changelog, if you would like it.

If you do not get an answer, you can also contact the WordPress.org Plugin Review Team at plugins@wordpress.org.

## Scope

In scope: the plugin's own code (this repository). Out of scope: WordPress core, other plugins and themes, and server configuration, unless the plugin makes them exploitable.
